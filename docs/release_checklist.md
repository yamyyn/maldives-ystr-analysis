# Release checklist

- Verify input coordinates; no automatic sign correction.
- Review cohort classifications, confirmation evidence, microvariants, multicopy states and count reconciliation.
- Verify panels, seeds, iterations, method settings and October 30 affected outputs.
- Verify raw external Arlequin results against frozen projects, labels, loci, settings and software version.
- Compare modern calculations and graphics against version-appropriate private results; explain every difference. The 338-row mapping is not numerical proof.
- Supply independent targets and fresh observations for applicable original audit keys. Do not copy expected values into observations.
- Approve sampling-map color/grayscale PDF/PNG/TIFF files; resolve numbering and captions.
- GPL-3.0-only is selected. Verify attribution and add the actual repository URL or DOI when available; do not invent an identifier.
- Set approval flags only after caption and private numerical/visual review. Flags record author decisions, not automated findings.
- Run tests and synthetic CI; inspect lockfile, paths, ZIP contents and hashes.
- Exclude genetic records, predictor files, identifiers, private coordinates, outputs, local configs, targets and credentials. Ignore rules alone are not a disclosure review.
- Inspect staged files before publishing. This runner assembles files locally and does not upload them.
