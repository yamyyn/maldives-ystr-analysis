# Methods and version policy

The October 30 revisions define affected predicted-parent reporting, predicted-parent DAPC, no-call visualization and revised haplotype catalogue. Other final figure/table recipes follow the locked inventory. The historical Figure 4/revised Figure 5 labels remain in source provenance. The finalized manuscript numbering is documented separately and must not be inferred from historical filenames. The sampling map remains an external author-reviewed input.

## Implemented calculations

- Frequencies use successfully typed denominators. Microvariants remain exact text states. Multicopy systems use sorted observed states, without inferred unobserved copies. Haplotype keys represent linked marker systems jointly. HMP is sum(p²), HD uses N/(N−1), haplotype DC is distinct haplotypes/N. Locus PD is 1−MP; these quantities are not interchangeable.
- Full and complete cohorts are analyzed separately. Revised sensitivity uses one joint population-stratified subsample per iteration, removing only complete profiles, matching excluded-profile population counts and retaining incomplete profiles in each simulation, and reuses each draw across national/regional/population scopes. Empirical lower/upper tails use a +1 correction; two-sided P is twice the smaller tail, capped at one. BH and Bonferroni apply to the six primary national metrics. Unstratified sensitivity is separate. Paired complete/excluded-stratum bootstrap is QC-only, not a replacement for primary random-removal P values.
- Marker panels are defined in CSV using the original assay-system definitions. Individual-marker contribution compares the full panel to leave-one-system-out panels, with individual-system diversity also reported.
- Accumulation uses original permutation-prefix counting. Singleton counts are not cumulative or necessarily monotonic. Rarefaction uses original exact hypergeometric expectations with subsampling intervals. Sharing distinguishes shared distinct haplotypes, matching-profile pairs and Jaccard similarity. Bootstrap uncertainty is an internal diagnostic, not independent replication.
- Structure preparation adjusts DYS389II by DYS389I. Decimal designations remain distinct categorical states for DAPC. The separate Arlequin branch excludes profiles with intermediate alleles at included loci before DYS389II adjustment; retained integer calls are exported unchanged. Eligibility is recalculated for each marker panel and audited without fixed study-result targets. Negative raw RST estimates remain unchanged. Visualization uses nonnegative RST directly (no square root), Cailliez PCoA, and NJ with separate raw/display trees. Only negative display branch lengths are zeroed.
- Spatial calculations use weighted coordinates and Haversine distances. Source coordinates are never automatically sign-corrected. Mantel permutes complete genetic-matrix labels and reports directional/two-sided empirical P. Original correlogram helpers use five distance bins, a negative binary-class correlation convention and progressive Holm correction. Empty/constant bins are explicitly undefined, never zero-filled.
- Geographic DAPC uses categorical one-hot allele features with centering and no variance scaling. Repeated stratified holdout CV selects PCs by lowest RMSE. Requested/effective feasible training, eligible groups, raw CV draws and apparent assignment are kept separate. This is not literal k-fold CV or independent validation.
- Predicted-parent posteriors sum leaf probabilities within configured parents, retaining modeled zero classes. Reporting preserves independently supplied parent calls and identifies the leading leaf within that parent. Leading-leaf fitness and best constituent fitness are distinct; fitness is not aggregated. Configured automatic-call thresholds are reported as a derived rule and must be checked against the predictor's batch provenance. Y-STR predictions are not SNP-confirmed haplogroups.
- October 30 haplogroup DAPC uses the configured 17 unaffected single-copy systems with DYS389 adjustment. The full exploratory fit retains observed groups, while CV excludes singleton categories from validation (default minimum two), retaining them in training. A separate fit/CV restricted to categories with at least five profiles provides rare-group sensitivity. Neither cohort is described as equivalent to an earlier grouping.

Geographic and October 30 parent DAPC have separate PC grids. The private template records the selected source grids. The parent branch adds rank-minus-one where feasible and excludes candidates below CV-group-count minus one, matching the revised rule. A further training-rank cap prevents infeasible PC requests on small synthetic cohorts. The demonstration deliberately uses a reduced grid; its selected PCs are not study results.

## Provenance and limits

Original pure calculation/parsing functions and final graphics/table recipes are retained where extracted; hashes are recorded in `source_recipe_provenance.csv`. Orchestration, parameterization, resampling integration and some supporting graphics are newly written adaptations. New supporting plots are not claimed to be exact historical renderings. The raw iteration objects and calculated tables support private comparison.

All 338 supplied trace entries are mapped to modern stages in `output_traceability.csv`; that mapping does not certify identical historical filenames, every workbook sheet, Word interoperability copies or private numerical equality. Historical superseded exports remain labelled as such. The 119 audit definitions still need independent targets and observed evidence on private data. A successful synthetic run, checksum or unit test cannot supply that evidence.
